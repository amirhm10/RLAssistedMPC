# Distillation Dueling Horizon History Report

## Summary

- Added a dueling-horizon-only distillation history report comparing saved `standard` and `mismatch` disturbed-fluctuation runs.
- Added a reproducible analysis script that rescans saved `input_data.pkl` bundles, rescales rewards under both current and legacy horizon reward settings, computes tracking and horizon-policy stability metrics, and writes local figures/CSV summaries.
- Generated local report figures under `report/figures/distillation_dueling_horizon_history_20260604/`; these remain ignored by Git per repo policy, but are regenerated by the script.

## Main Findings

- Earlier successful-looking runs were partly helped by legacy reward parameters, especially lower T85 penalty and wider temperature band.
- Some older trajectories still beat OF-MPC under current reward scoring, so the difference is not only cosmetic reward drift.
- Recent poor runs mainly show T85 degradation and excessive horizon-policy churn, especially after widening to the 263-action horizon grid.
- Recommended next horizon ablations are to keep the current 87-action recipe for SG-dueling-DQN handover tests, or use a reduced `Np = 6..11`, `Nc = 2..11` grid for a smaller stability-focused candidate set.
