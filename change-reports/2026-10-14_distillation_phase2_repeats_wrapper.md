# Distillation Scenario 2: ten parallel repetitions in five sequential channels

The author requested a distillation counterpart to the polymer repetition wrapper, preserving the existing experiment settings and sources while running ten repetitions together and five channels sequentially. Aspen models must be numbered 1 through 10 because a model cannot be opened by two concurrent runs.

Added `run_distillation_phase2_repeats.py`, `DISTILLATION_PHASE2_REPEATS.md`, and `tests/test_distillation_phase2_repeats.py`. The default plan executes five paired seeds in SG/plain modes across horizon, weights, Markov, residual, and combined: 50 unchanged complete `temperature_flip_200_100` studies, with ten concurrent repetitions per channel. Each channel assigns SG to Aspen simulations 1–5 and plain to 6–10, then waits for every saved result, Aspen cleanup, and process exit before reusing the files in the next channel.

The wrapper runs the existing entrypoint files through process-local defaults. It preserves all scientific values outside study/mode selection and training seeds. Distillation's single-channel scripts derive their algorithm from `agent_mode`; combined uses `combined_agent_mode`. Combined's standalone parity checks receive the same seeds as its constituent agent settings. Explicit per-worker paths override the usual family presets and shared manual/snapshot overrides without editing shared configuration. Matching snapshot paths are resolved through the existing resolver. OS file locks prevent collisions between cooperating wrapper workers. A worker-local subclass ensures cleanup on errors and partial construction, avoids duplicate close calls, and requires successful cleanup before accepting saved results.

Dependency/model preflights precede batch creation. Outputs, logs, seeds, model assignments, attempts, and provenance are isolated and recorded. Resume preserves saved runs and their original Aspen assignments, and retries failed jobs into fresh attempt directories. The existing dirty polymer wrapper is retained exactly as found.

Files inspected: root `AGENTS.md`; the polymer repetition wrapper, its tests and guide; the five active distillation RL entrypoints; `systems/distillation/config.py`, `notebook_params.py`, `plant.py`, `scenarios.py`, `data_io.py`, and `__init__.py`; `utils/notebook_setup.py`; existing distillation profile/combined tests; agent RNG handling; `.gitignore`; and relevant README setup instructions. Files changed: only the three new files listed above and this change note.

Validation at initial implementation: all 17 focused checks passed, including actual-default preservation, all ten combined parity configurations, real ten-process overlap, channel barriers, file locks, failure recovery, reserved-attempt recovery, and cleanup guards. The standard-library-only dry run shows 50 repetitions, five channels, and exactly files 1–10 per channel. Read-only preflight against the existing scientific interpreter found all ten models and the corresponding snapshot paths in the configured Aspen folder. Full Aspen execution and scientific training were not launched.

Final verification also passed all 13 existing distillation temperature-flip profile and combined-runner checks, for 30 passing checks in total. SHA-256 comparison confirmed all 124 pre-existing tracked Python files retain their starting contents, including the already modified polymer wrapper. Two environment specification files changed independently during this work; they were not edited or included in this wrapper change.
